Why Python backend + Next.js frontend (not full Next.js)?
Google ADK is Python-only. ChromaDB is Python-native. PyMuPDF is Python. Forcing all of this into a Node.js runtime adds unnecessary friction. Keep the AI pipeline in Python, expose it via FastAPI, consume it from Next.js.

Agent 1 — Intake (intake_agent.py)
Person 1
System prompt strategy
Guide Gemini to ask exactly 6 fields, one at a time, in plain conversational Hindi/English. After all fields collected, output JSON and nothing else.
from google.adk.agents import Agent from schemas.profile import UserProfile SYSTEM_PROMPT = """ You are a helpful assistant for Indian businesses seeking grants. Ask these fields ONE AT A TIME in a friendly conversational tone: 1. Business name and what it does 2. Entity type: startup / SMB / NGO / other 3. Primary sector: edtech / healthtech / agri / fintech / other 4. State and city of operation 5. Team size (number of employees) 6. Annual revenue in INR (approximate is fine) After collecting all 6, output ONLY a JSON object matching: {"name": "", "type": "", "sector": "", "state": "", "city": "", "team_size": 0, "revenue_inr": 0, "funding_purpose": ""} No other text after the JSON. """ intake_agent = Agent( name="intake_agent", model="gemini-2.0-flash", instruction=SYSTEM_PROMPT, output_key="user_profile_raw" )
Agent 2 — Research (research_agent.py)
Person 2
Two-source strategy: RAG + live search
Run ChromaDB query and web search in parallel using asyncio.gather. Merge, deduplicate by scheme name, return combined list.
import asyncio from rag.retriever import query_schemes from google.adk.agents import Agent from google.adk.tools import google_search async def research_fn(profile: dict) -> list: query = f"{profile['sector']} grants {profile['state']} {profile['type']}" rag_results, live_results = await asyncio.gather( query_schemes(query, top_k=15), run_web_search(query) ) combined = merge_and_dedupe(rag_results, live_results) return combined research_agent = Agent( name="research_agent", model="gemini-2.0-flash", tools=[google_search], output_key="raw_schemes" )

How all 4 agents wire together in pipeline.py
from google.adk.agents import SequentialAgent from agents.intake_agent import intake_agent from agents.research_agent import research_agent from agents.validator_agent import validator_agent from agents.planner_agent import planner_agent govgrant_pipeline = SequentialAgent( name="govgrant", sub_agents=[ intake_agent, # Step 1: collect profile research_agent, # Step 2: find schemes validator_agent, # Step 3: rank matches planner_agent, # Step 4: build output ] )
FastAPI endpoint (api/routes.py)
from fastapi import FastAPI from fastapi.responses import StreamingResponse from orchestrator.pipeline import govgrant_pipeline app = FastAPI() @app.post("/api/run") async def run_pipeline(body: dict): session_id = body["session_id"] user_message = body["message"] async def event_stream(): async for event in govgrant_pipeline.run_async( user_id=session_id, message=user_message ): yield f"data: {event.model_dump_json()}\n\n" return StreamingResponse(event_stream(), media_type="text/event-stream")
Next.js frontend consumption (lib/api.ts)
export async function streamPipeline( sessionId: string, message: string, onChunk: (event: PipelineEvent) => void ) { const res = await fetch("/api/stream", { method: "POST", body: JSON.stringify({ session_id: sessionId, message }), headers: { "Content-Type": "application/json" } }); const reader = res.body!.getReader(); const decoder = new TextDecoder(); while (true) { const { done, value } = await reader.read(); if (done) break; const line = decoder.decode(value).replace("data: ", ""); try { onChunk(JSON.parse(line)); } catch {} } }
These Pydantic models are the source of truth. All agents validate against them.
UserProfile (schemas/profile.py) — output of Agent 1
class UserProfile(BaseModel): name: str type: Literal["startup", "smb", "ngo", "other"] sector: str state: str city: str team_size: int revenue_inr: int funding_purpose: str
Scheme (schemas/scheme.py) — output of Agent 2
class Scheme(BaseModel): name: str source_url: str source_type: Literal["live", "offline"] criteria_text: str deadline: Optional[date] max_revenue_inr: Optional[int] eligible_types: list[str]
RankedScheme — output of Agent 3
class RankedScheme(Scheme): match_score: int # 0-100 match_reason: str urgency_score: float # deadline multiplier composite_rank: int # 1-5
GrantReport — output of Agent 4
class ActionCard(BaseModel): scheme_name: str deadline: Optional[date] portal_url: str top_conditions: list[str] # max 3 class GrantReport(BaseModel): user_profile: UserProfile top_schemes: list[RankedScheme] documents: list[str] # master checklist action_cards: list[ActionCard] cover_summary: str
Practical day-by-day plan for a team of 4.
D1
Day 1 — Foundations (everyone)
Clone repo. pip install google-adk chromadb fastapi pymupdf pydantic sendgrid. Define all 4 Pydantic schemas together. P2 runs ingest_schemes.py to build ChromaDB. P1 scaffolds Next.js. P3+P4 write mock fixtures.
D2
Day 2 — Agent cores
P1 builds intake agent + chat UI with streaming. P2 builds RAG retriever + web search merge. P3 builds hard filter + LLM scorer. P4 builds planner prompt + alert scheduler. All test against mock data independently.
D3
Day 3 — Integration
Wire all 4 agents into SequentialAgent in pipeline.py. P1 connects frontend to FastAPI stream endpoint. Run end-to-end with the demo input: "edtech startup, Bengaluru, 8 people, ₹40L revenue". Fix schema mismatches.
D4
Day 4 — Polish + demo prep
P1 polishes UI — agent status badges, loading states, copy button on cover summary. P2 adds 10 more schemes to ChromaDB. P3 tunes scoring weights. P4 tests email alerts. Everyone rehearses the 3-minute demo script.
